## Ce qui vaut pour tous

- **Le lieu** : un seul, à taille vraie. L'origine est le centre du caisson (l'arrière de la tourelle) ; **le char regarde vers −x** ; la cloison des portes regarde −x (vers l'équipage) ; **+z est la gauche du char, le côté du chargeur (« toi »)**. az 0 : caméra sur le flanc +z ; az −90 : devant ; az +90 : derrière. **À az −40/−46 la cloison (portes, tringle, came) se lit de trois quarts.** L'établi est le même lieu, char, sol et feu effacés (`SET.BENCH`).
- **La caméra en plan-séquence** (`docs/recette-actes.md` § « Le plan-séquence ») : **un `D.path` par lieu**, une clé par idée (1 à 3 s d'écart), 6 à 15° d'angle de plus à chaque clé ; **az DÉCROÎT dans tous les trajets du film** (l'ordre est écrit au-dessus de `VIEW` dans `world.js`) ; `to: "go"` partout (on entre lancé dans la coupe suivante). Rien d'autre ne pilote la caméra pendant un `path` (`punch`, `jolt` s'y ajoutent). Coupes du film, et rien de plus : `toscene` 8,98 · `tobench` 18,38 · `toprincipe` 29,18 · `torest` 36,39 · `tozero` 45,19 · `towide` 56,14 · 58,81 (invisible) · `tocta` 64,34 · `tolike` 73,60 · `toabo` 77,01 · `toloop` 83,07. - **Tout mécanisme de trois quarts dès le plan** : un profil devient une lame illisible à 270 px. Portes, came, tringle : az −35 à −55 ; le panneau : el ≥ 20 ; jamais la cloison de face (az −90) ni par la tranche.
- **La grille de rétention** : 0 → 0,5 s le sujet bouge (le panneau qui se soulève, les flammes dessous), pas la seule caméra ; **jusqu'à 25 s, un geste ou un changement toutes les 2 à 3 s, aucune plage lente de 2 s** ; un son dans le souffle qui suit chaque mot-clé — **déjà posés** dans `sfx` (51 sons, tous dans les souffles : n'en ajoute aucun sur un mot).

- **À ne jamais montrer** : une détonation (le film dit « la poudre flambe ») ; un équipage blessé, brûlé, un corps en gros plan ; un pays, un insigne, un char reconnaissable ; le pilote « juste devant » le caisson ; la porte qui s'ouvre « au genou » ; l'autre tourelle avec une porte ou une cloison ; le feu qui sort ailleurs que par le haut.
