## Ce qui est décidé avant la première planche

- Minutage estimé lu avec `npm run script -- 011` ; tout instant vient de `D.times` (repères d'`episode.json` ou `beat:mot`).
- **Un seul mouvement pour l'accroche** (0 → `tosans`) : POSE0 → ta vitre (par rapport, 800 → 300, avec une courbe « déjà en route » dès l'image 1) → plongée par rapport vers le fusible sous la banquette (300 → 72) → recul par rapport le long du câble (65 → 640) → la batterie → la voiture entière, éteinte (le cadre de la première image).

À l'explosion : `flow` → 0 et `hv` → 0,55 (les tirets raccourcissent, on voit que quelque chose s'est passé), puis `hv` → 0 de « quatre cents » à `ms`, pendant que le câble entre dans le cadre.
- **« Et la carrosserie… » : pas `VIEW.door`** mais le cadre large de la première image (trois quarts arrière) : même cadre que la voiture éteinte quatre secondes plus tôt, autre issue — la lumière signal gagne la caisse. Le sauveteur n'y est pas (`rescuer` 0).
