## Du thème à la vidéo

```
npm run new     -- 003 ascenseur "Ascenseur"   crée episodes/003-ascenseur depuis kit/template
npm run script  -- 003                         script, minutage, repères
npm run credits                                solde ElevenLabs (appel gratuit)
npm run voice   -- 003                         séance de doublage : annonce le coût, n'enregistre rien sans --budget ; affiche la courbe de tension, acte par acte
npm run essai   -- 003 --file essais.json      banc d'essai voix : un passage sous plusieurs directions, mesuré contre le narrateur du film (même règle : rien sans --budget)
npm run review  -- 003 [--from s --to s --every s]   planche-contact : le film entier sur une page
npm run look    -- 003 --at 0.04,beat:mot+0.2  images d'essai côte à côte, zones TikTok par-dessus (renders/<ep>-essais.jpg)
                   --file essais.json          …chacune avec sa pose de caméra : [{ "at": …, "pose": { "d": 240 }, "label": … }]
                                               …et, dans un film monté avec `kit/lib/direct.js`, son état : `"state": { "explode": 1 }` — un décor se juge avant qu'un acte existe
                   --out <fichier>             la planche ailleurs que dans renders/ (toute planche de travail : Merwan voit renders/)
npm run snap    -- 003 --at 1,8,20             images en pleine résolution
npm run check   -- 003                         lint + audits HyperFrames, doit passer
npm run preview -- 003                         lecture en direct dans le studio
npm run render  -- 003 [--draft]               MP4 dans renders/, audio à -14 LUFS
npm run qa      -- 003 [--file renders/003-ascenseur-draft.mp4]   le MP4 rendu (ou le brouillon) : voix calée, niveau, aucune image parasite, fluidité
                                               …et le « rythme » (depuis le 21/10) : mouvement de la première demi-seconde, plages lentes avant 25 s, sons qu'un téléphone joue, sons posés sur un mot
npm run cover   -- 003                         couverture de grille
npm run phone   -- 003                         copie du film sous 30 Mio (renders/<ep>-iphone.mp4), pour l'envoyer au téléphone par la conversation
npm run social  [-- --out <dossier>]           deux stories Instagram (une vers TikTok, une vers YouTube Shorts, avec l'emplacement de l'autocollant de lien) et la bannière YouTube (2560×1440, l'essentiel dans la zone sûre 1546×423) : de vraies images 3D d'un film, notre typo, nos trois couleurs, aucun logo de plateforme — `scripts/social.mjs`
                   --only facebook|stories|youtube   une seule famille ; `facebook` : l'image du post de présentation de la page (1080×1350, `renders/post-facebook.png` : la phrase du compte, la flamme du 012, trois dossiers ouverts en vignettes — `FILES`)
npm run chrono  -- 012 <étape> | stop          le chronomètre de la fabrication : une étape commence (la précédente se ferme)
                   agent <nom> --genre decor --modele opus --jetons N --min N --outils N --images N   ce qu'a coûté un agent (les chiffres de sa notification de fin)
                   jauge --session N --hebdo N --quoi "…"   la jauge du forfait, au début, au milieu, à la fin
npm run metrics [-- 012]                       ce que coûte un dossier (temps par étape, jetons par agent, calcul, jauge) et ce qu'il rapporte (audience)
npm run front                                  bureau de publication + cabine d'écoute, pour l'iPhone (même Wi-Fi) — lancé depuis une session il s'arrête au bout de 2 h : pour le garder ouvert, Merwan double-clique `publier.cmd` (si un bureau tourne déjà, sa fenêtre l'annonce, donne l'adresse et prend le relais dès que l'autre s'arrête)
```

Ordre de travail : recherche et faits → script (`episode.json`) → **accroche validée par Merwan** → **voix** (elle fixe le minutage) → modèle 3D → **habillage** (le décorateur : `docs/recette-decorateur.md`) → mise en scène (`look` pour trouver chaque cadrage : dix poses en un coup d'œil, sans rendu) → `review` jusqu'à ce que chaque vignette se lise → `check` → `render --draft` puis `qa --file …-draft.mp4` (les images parasites se corrigent sur le brouillon, 80 s de rendu) → `render` → `qa` → `cover`. Si la mise en scène a été montée sur un minutage estimé en attendant l'accord voix (005), elle se **repasse phrase par phrase** une fois la voix enregistrée, avec `look` par paquets de huit images : sur le 005, cette passe a fait refaire la moitié du film (voir « Dossiers »). Le `build` (lancé par toutes ces commandes) tient à jour ce qui dépend du minutage : la voix montée en un fichier (`audio/voix.wav`) et l'habillage sonore (`audio/bed.wav`).

### La chaîne courte (à partir du 008)

Merwan, dans la nuit du 7 au 8 octobre, après le 007 (≈ 4 h 30 de fabrication, ≈ 2,7 M de jetons d'agents, dans une conversation devenue énorme) : « ça marche mais ça consomme de fou », « aussi bon et qualitatif mais plus rapide à créer ». Cible : **≈ 2 h et ≈ 1,5 M de jetons par épisode, sans rien céder sur l'image**. Ce qui suit remplace l'habitude de tout reconstruire.

- **Une conversation neuve par épisode.** Chaque message relit toute la conversation : fabriquer un épisode à la suite d'un chantier coûte plusieurs fois son prix. C'est le projet (ce fichier, `docs/`, le code) qui porte la mémoire, pas la conversation.
- **Le squelette d'un épisode (étape 0, faite le 2026-10-08 au début du 008)** — `npm run new` crée désormais un épisode qui tourne et passe `check` tel quel, découpé pour que les actes se montent en même temps :
  - `src/model.js` le système · `src/world.js` **le contrat** : les décors, `FIRST` (l'état du monde à la première image : la liste fermée des nombres que les actes ont le droit de bouger), `POSE0`, `VIEW` (les poses qu'un acte rend au suivant), `BENCHED` / `STAGED` (ce qu'une coupe vers l'établi ou vers le décor remet d'aplomb) et `apply(S, time)` · `src/acte1.js`, `acte2.js`, `acte3.js`, `fin.js` : rien que des `st` / `shot` / `cut` / `tl` sur des instants lus dans le script · `src/main.js` : trente lignes de colle, l'horloge et le compteur de l'en-tête.
  - `kit/lib/direct.js` (`createDirector`) porte ce que chaque `main.js` réécrivait : `st`, `now`, `shot` (et sa plongée par rapport, `fromD`), `cut` (pose complétée : `fov` 28, `drift` 0,3), `jolt`, `show` / `hide` / `blip`, `panel`, `follow` et `chip` (étiquette posée sur un point, ou fixe), `readout` (un texte de l'en-tête réécrit à chaque image), `ride` (la caméra suit un objet), `verdict` (le nom du compte s'allume), `loop` (le retour à la première image : tout nombre de l'état qui n'est pas revenu y glisse tout seul) et `commit` (accroche, sous-titres, plans posés dans l'ordre) — qui **prévient dans la console si la dernière image n'est pas la première**, en nommant les nombres fautifs. Avec `along`, `ramp`, `reaim`, `moved`.
  - `kit/lib/blocks.js` porte les blocs qui reviennent : `makeBench(taille)` (l'établi mat, sa grille, son halo), `setMood`, `benchCut` (le raccord décor → établi sur le même objet, à la même place), `retitle` (le titre barré de la chute, avec `#title-shade`, désormais dans `brand.css`), `likeCall`, `nextFile`, `commentCall` (les trois CTA et leurs chevrons). Leur balisage est dans `kit/template/index.html`.
  - Les épisodes 001 à 007 gardent leur `main.js` d'origine : on ne les réécrit pas.
- **Avant la 3D, un seul aller-retour avec Merwan** : faits (un agent) → contre-vérification (un agent) → script → un message : l'accroche et le budget voix, oui ou non → voix. Faits, scripts et voix peuvent se préparer pour deux ou trois épisodes d'un coup, validés ensemble.
- **Agents** : recherche et contre-vérification sur un modèle léger (`model: "sonnet"`, `effort: "medium"`) ; modèles 3D et mise en scène sur le modèle de la session. Un agent par fichier, liste fermée, 45 images lues au plus, un journal sur le disque. Jamais d'audit, jamais de relecteur par agent : la relecture, ce sont deux planches `look` de 24 instants lues par celui qui orchestre, puis `check`, `render --draft`, `qa`.
- **Réutiliser les décors** au lieu d'en modéliser un par épisode : l'établi (tous), la pièce et le tableau (`004/src/room.js`), le hall (`006/src/hall.js`), la route (`002/src/road.js`), la gaine (`003/src/shaft.js`), le ciel, la piste et l'avion (`007/src/jet.js`), le personnage de verre et sa main (`kit/lib/figure.js`). Le micro-ondes (009) part de la pièce du 004 ; le paratonnerre (008) du ciel du 007. Un décor qui sert deux fois monte dans le kit.
- **Ce qui a déjà raccourci la boucle** : `look` sur la carte graphique (huit images en 3 s), brouillon rendu en 1 min 40, rendu final en 2 min 20.
- **Mesuré sur le 008 (nuit du 7 au 8 octobre)** : ≈ 2 h 30 de fabrication (plus ≈ 40 min pour l'étape 0, faite une fois) contre 4 h 30 pour le 007 — la cible de 2 h est approchée. **Les jetons, eux, ont augmenté : ≈ 3,5 M d'agents (9 agents) contre 2,7 M** — la cible de 1,5 M est manquée de loin. Où ils sont partis : trois décors neufs à 420–530 k chacun (45 images lues, et une barre relevée en cours de route après la remarque de Merwan), quatre actes à 325–430 k, les faits (315 k, soixante pages au lieu de trente) et la contre-vérification (310 k). Ce qui doit les faire baisser au 009 : **des décors qui existent déjà** (la maison de `008/src/house.js` est une maison entière, avec sa cuisine : le micro-ondes y entre), 30 images par agent et non 45, une recherche tenue à trente pages, une contre-vérification qui ne relit que les phrases du script.
- **Ce qui a marché, à refaire tel quel** : la recette des agents (`docs/recette-agents.md`) ; un `plan.js` sans import que tous les décors lisent (ils se construisent en même temps contre des bouchons) ; le plan de mise en scène phrase par phrase, écrit sur les instants de la vraie voix (`docs/008-actes.md` : c'est le modèle) ; quatre actes montés en parallèle en une demi-heure, chacun commençant par une coupe à l'état complet ; la relecture par celui qui orchestre sur trois planches de 28 instants, puis `check`, brouillon, `qa`.
- **Ce qui a coûté** : les agents ont rendu leurs fichiers pendant que la conversation attendait un message — relancer la relecture dès la notification, sans attendre Merwan. Une image d'échafaudage est arrivée sous ses yeux (voir « Avant de livrer »).
- **Le décorateur (depuis le 2026-10-16, courts et longs)** : Merwan voulait des décors « plus immersifs ». Un agent passe après les décors et AVANT la planche des candidates de la première image et les actes : il donne au lieu la vie qu'il a dans la réalité (ce qu'on y pose, ce qui l'éclaire, ce qui flotte dans son air, ce qu'on voit au loin), aux rayons X, en `ink`, jamais sur le système ni devant lui, dans son seul fichier `src/habillage.js` (plus quatre lignes d'accroche dans le décor). Recette : `docs/recette-decorateur.md` ; catalogue : `kit/lib/details.js` (`makeDresser`). Essayé sur le 020 (Taipei la nuit en contrebas, les spots de la salle de la boule), déjà en ligne : l'essai sert de référence et ne se rend pas à nouveau ; validé par Merwan le jour même pour **les dossiers suivants** ; `qa` sans image parasite. Coût visé : un agent, 15 à 20 min, 150 à 250 k jetons sur un court ; un ou deux, 250 à 400 k, sur un long — à mesurer (`chrono … habillage`). Un décor réutilisé garde son habillage : on ne le repaie pas.

### Mesurer pour aller plus vite (depuis le 012)

Merwan, le 08/10 au soir, en lançant le 012 : « prendre en compte le temps et faire des metrics pour améliorer et scale le truc ». Depuis, **tout dossier est chronométré** : `scripts/metrics.mjs`, données dans `metrics/` — `commandes.jsonl` (écrit tout seul par chaque `npm run …` : quoi, quel dossier, combien de temps), `production.json` (les étapes, les agents, la jauge : tenus par celui qui orchestre avec `npm run chrono`), `audience.json` (les chiffres TikTok de Merwan, recopiés : c'est là qu'ils vont désormais, et `npm run metrics` en tire les abonnés pour 1 000 vues, la part regardée, la tenue à 5 s). `npm run metrics` donne le tableau ; les dossiers 007 à 011 y sont reconstitués d'après ce fichier.

Le rituel, qui ne coûte rien : `chrono <étape>` à chaque changement d'étape (`faits`, `decors`, `actes`, `relecture`, `brouillon`, puis `voix`, `passe`, `rendu`), `chrono agent …` à chaque notification de fin d'agent (elle donne ses jetons, sa durée, ses appels d'outils ; lui dit ses images lues), `chrono jauge` au début, à mi-parcours et à la fin (`get_usage`).

**Ce que dit la première mesure complète (012, sans voix : 2 h 03, 3,19 M de jetons d'agents, 9 agents, +66 points de la fenêtre de 5 h, +9 points d'hebdo)** :

- **Le plafond n'est pas le temps, c'est la fenêtre de 5 h : un dossier en mange les deux tiers.** Un seul dossier par fenêtre, lancé juste après une remise à zéro ; deux dossiers à la suite ne tiennent pas. À ce prix l'hebdo porte une dizaine de dossiers.
- Le temps part à parts égales dans les décors (52 min, 42 %) et les actes (51 min, 41 %) ; tout le reste (faits, script, relecture, brouillon, contrôle, couverture) tient en 20 minutes. Ces deux étapes durent ce que dure leur agent le plus lent (`hob.js` 50 min, `acte2.js` 49 min) : **couper en deux le fichier le plus lourd** (l'acte 2 : l'éclaté d'un côté, la démonstration de l'autre) rendrait un quart d'heure.
- Les jetons : trois décors neufs 1,30 M (435 k chacun), quatre actes 1,38 M (346 k chacun), faits et contre-vérification 0,5 M sur le modèle léger (qui pèse peu dans la jauge). Le budget de 30 images par agent a été tenu par les sept agents, à l'image près, sans baisse de niveau : on le garde. **La cible de 1,5 M ne s'atteint qu'en ne modélisant pas** : un décor neuf au lieu de trois (≈ −0,9 M), c'est le premier levier — choisir et écrire les dossiers pour ce qu'ils réutilisent (la cuisine a maintenant sa plaque à gaz, sa casserole et un feu : `012/src/hob.js`, `fire.js`).
- **Celui qui orchestre coûte cher lui aussi** : sa conversation finit à ≈ 510 k jetons, relus à chaque appel (une centaine d'appels) — d'où +9 points d'hebdo pour 3,2 M, contre ≈ +6 par dossier la nuit des trois (9 M, +17). Ce qui la gonfle : lire un dossier de faits en entier (le message final de l'agent suffit, avec ses sections « à ne pas dire »), relire des planches de 30 vignettes, écrire de longs fichiers par des commandes. À faire : planches de relecture en deux fois 28 au plus, aucun fichier lu en entier s'il a un résumé, et **ne plus rien appeler pendant que les agents travaillent** (chaque appel relit tout).
- La contre-vérification tenue aux seules phrases du script : 229 k au lieu de 310 k, et elle a fait changer cinq formulations. Les faits tenus à 30 pages : 276 k au lieu de 315 k.
- Un agent en a corrigé un autre (la fin a trouvé un repère oublié dans l'acte 1, qui décalait la première image sans que rien ne le signale) : la comparaison première / dernière image reste dans la consigne de la fin.
