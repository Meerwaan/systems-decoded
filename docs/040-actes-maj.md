# 040 — ce que les décors ont changé (à lire avant docs/040-actes.md)

1. **Première image = candidate C** (« au ras de l'ourlet ») : `POSE0 = { tx 0, ty 60, tz -20, d 560, az -22, el -5, fov 44, shift 40 }`, `FIRST.front = -6`, `FIRST.heat = 0.4` (à 0,7 la feuille vire au rose pâtisserie). La dernière image (88,0) la retrouve : ne pas y toucher dans `fin.js`.
2. **Poses changées dans `VIEW`** : `crest` (crete, vue à 270 px), `canyon` (feu : el 32, plus bas la crête cache le front), `back` (feu, NON vérifiée), `section` (compromis abri lisible / rayons entrants : tz -50, d 620), `inside`, `mouth`, `packBench`, `foilClose`, `shovelClose` ; `gapClose`, `fibreClose`, `innerClose` reculés à d 330. Toute pose se vérifie sur ta planche.
3. **Le feu** (`feu.js`) : `front` en mètres sur z, `lean` couche vers +z, `bench` cache tout le feu sur l'établi ; les langues proches de la caméra s'effacent entre 3,2 et 9,5 m. Le haut du cadre reste orange : garde l'en-tête lisible (fond `#hud-shade` renforcé dans index.html).
4. **La crête** (`crete.js`) : `deploy` couche les 72 équipes chacune à son seuil, `burn` éteint la forêt, `char` consume le manche (`A.shovel` suit le point qui brûle), `duo` cache deux coques. `zeroWide` : les flammes passent sur la caméra — préférer un plan plus serré.
5. **L'abri** (`model.js`) : `explode` lève les couches en pages, `cut` ôte la moitié −x, `rise` > 0,5 est une coupe (debout à côté), `glue` puis `hole` sur le coin. Battement de l'ourlet à juger au brouillon. En gros plan sous `heat` fort, des pavés roses : garder `heat` ≤ 0,6 dans les gros plans.
6. **Rythme** (leçon du 039) : dans les 25 premières secondes, une coupe ou un geste du sujet toutes les 2 à 3 s ; le sujet bouge par lui-même (flammes, ourlet, braises), jamais la seule caméra.
